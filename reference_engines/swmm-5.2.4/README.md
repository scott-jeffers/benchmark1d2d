## Fetch (Windows)

```powershell
$rel = "https://github.com/USEPA/Stormwater-Management-Model/releases/download/v5.2.4/swmm-solver-5.2.4-win64.zip"
Invoke-WebRequest $rel -OutFile vendor/swmm-solver-5.2.4-win64.zip
Expand-Archive vendor/swmm-solver-5.2.4-win64.zip -DestinationPath vendor/extracted -Force
New-Item -ItemType Directory -Force bin | Out-Null
Copy-Item vendor/extracted/swmm-solver-5.2.4-win64/bin/runswmm.exe, `
          vendor/extracted/swmm-solver-5.2.4-win64/bin/swmm5.dll, `
          vendor/extracted/swmm-solver-5.2.4-win64/bin/swmm-output.dll bin/
```

Verify:

```powershell
Get-FileHash bin/swmm5.dll -Algorithm SHA256
# must match SHA256SUMS
```
