# Scores and rankings (retired)

Ranks, the OpenHydro rating and the leaderboard were retired on 20 November
2026 by [evidence protocol 4.0](evidence.md) ([ADR-0004](../adr/ADR-0004-evidence-not-rankings.md)).
The suite now reports evidence: each result's measures, its kind of evidence
(verification, validation or comparison), the capability it bears on, and how
the model was set up. Nothing is ranked and no number is combined across tests.

The measures of a single result are unchanged: [scoring_v3.md](scoring_v3.md) §1–2.
The retired text is in this file's git history.
