# Sewer network routing: what to build

EXTRAN Manual Example 1: a branched sewer network with surcharge, three inflow hydrographs and 8 hours of dynamic-wave routing. Your engine is compared with EPA SWMM 5.2.4, element by element.

## Build
Nothing to build: run `inputs/network.inp` (EPA SWMM 5 format) as it is, with your engine's own defaults.

## Run
The whole period in the file (8 hours), reporting every 15 minutes.

Results stay in the file's own units (this file is in US units: feet and ft³/s).
