# Pump station switched by rules: what to build

A 90-node sanitary sewer with two pump stations whose pumps are switched on and off by control rules on wet-well depth. Your engine is compared with EPA SWMM 5.2.4: depths, flows, and when each pump switches.

## Build
Nothing to build: run `inputs/network.inp` (EPA SWMM 5 format, SI units) as it is, with your engine's own defaults.

## Run
The whole period in the file (36 hours), reporting every 30 s.
