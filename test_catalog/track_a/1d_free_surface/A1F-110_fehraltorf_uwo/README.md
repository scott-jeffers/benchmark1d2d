# A1F-110 — Fehraltorf Urban Water Observatory

The [UWO dataset](https://doi.org/10.25678/000C5K) (ESSD 2026, CC0) covers 70 hydraulic sensors in a Swiss combined sewer, 2019–2021, with an EPA SWMM base model.

The validation design is declared in the manifest:

- **Calibration:** 2019.
- **Scored:** January–July 2020, before the network change.
- **Held back for a blind round:** records after 2021, still to be requested from Eawag.

**Status: draft.**
