# A1F-020 — Bélanger hydraulic jump

## Physics

Steady free-surface hydraulic jump. Sequent depths satisfy the Bélanger
relation from momentum conservation across a discontinuous free-surface shock.

## Citation

Classical Bélanger sequent-depth equation (1828), as treated in open-channel
hydraulics texts (Chow 1959; Henderson 1966).
