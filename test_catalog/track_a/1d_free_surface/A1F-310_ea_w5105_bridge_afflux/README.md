# A1F-310 — EA W5-105 Test J: measured bridge afflux

The Environment Agency river benchmark (W5-105, 2004) Test J gives the measured afflux at a bridge at four flows: the rise in upstream level compared with the same channel without the bridge.

This is the first hydraulic-structures case in the catalogue.
