# A1F-300 — EA W5-105 river benchmarks with exact answers

The Environment Agency's 2004 benchmarks of river modelling software (R&D Technical Report W5-105) include tests with analytical answers:

- **Test A:** five parts of quasi-steady, gradually varied flow.
- **Test F:** a monoclinal flood wave.
