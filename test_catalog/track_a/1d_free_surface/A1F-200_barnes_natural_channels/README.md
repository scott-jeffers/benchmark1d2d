# A1F-200 — Natural channels with verified roughness (Barnes 1967)

Fifty surveyed natural reaches from USGS Water-Supply Paper 1849, each with a measured peak discharge, surveyed cross sections, the high-water profile and the Manning's n computed from them.

**Status: draft.** The reach data must be transcribed from the publication (public domain, [doi:10.3133/wsp1849](https://doi.org/10.3133/wsp1849)).

Two variants, scored separately:

- **n given:** Barnes' computed n is supplied. This checks the model's conveyance and loss method.
- **n chosen:** only the photographs and channel descriptions are supplied. This tests the roughness selection engineers make every day.
