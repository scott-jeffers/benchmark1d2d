# A1P-021 — Bergant slow closure / column separation

## Physics

Transient pressurized flow with slow valve closure. Vapour cavities form when
pressure drops to vapour pressure (column separation); collapse produces
secondary pressure peaks.

## Citation

Bergant, A., and Simpson, A. R. (1999). "Pipeline column separation flow
regimes." *J. Hydraul. Eng.*, 125(8), 835–848.
https://doi.org/10.1061/(ASCE)0733-9429(1999)125:8(835)
