# A1P-001 — Darcy–Weisbach single pipe

## Physics

Steady pressurized flow in one circular pipe. Frictional head loss follows
the Darcy–Weisbach relation.

## Citation

Darcy–Weisbach classical friction formula as documented in Rossman et al.
(2020), *EPANET 2.2 User Manual*, EPA/600/R-20/133.
