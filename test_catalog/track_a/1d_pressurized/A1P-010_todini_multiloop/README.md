# A1P-010 — Todini multi-loop network

## Physics

Steady analysis of a multi-loop pressurized network. Continuity at nodes and
energy around loops; solved by the Todini–Pilati global gradient algorithm.

## Citation

Todini, E., and Pilati, S. (1988). "A gradient algorithm for the analysis of
pipe networks." *Computer Applications in Water Supply*, Vol. 1.
