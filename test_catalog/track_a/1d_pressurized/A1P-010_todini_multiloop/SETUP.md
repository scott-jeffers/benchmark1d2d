# Looped water network: what to build

A small gravity-fed network with two loops (Alperovits and Shamir, 1977): one reservoir, six junctions, eight 1 km pipes, Hazen–Williams friction.

## Build
- The network in `inputs/network.json`, also given as an EPANET file: `model/A1P-010.inp`.
- Reservoir head 210 m; junction elevations and demands as listed; Hazen–Williams C = 130 for every pipe.

## Run
A single steady solution.
