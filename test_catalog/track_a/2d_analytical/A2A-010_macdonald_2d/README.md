# A2A-010 — MacDonald 2D manufactured channel

## Physics

MacDonald-style **manufactured** steady free-surface depth over a known bed
in 2D: streamwise Gaussian bump with mild spanwise cosine modulation, constant
unit discharges `(qx, qy)`, and `zb = zs0 − h`. See module docstring in
`references/macdonald_2d.py` for the exact construction (friction omitted in
MVP).

Analytic generator: `references.macdonald_2d.depth_velocity`.

## Citation

MacDonald, I., Baines, M. J., Nichols, N. K., and Samuels, P. G. (1997).
"Analytic benchmark solutions for open-channel flows." *J. Hydraul. Eng.*,
123(11), 1041–1045. https://doi.org/10.1061/(ASCE)0733-9429(1997)123:11(1041)
