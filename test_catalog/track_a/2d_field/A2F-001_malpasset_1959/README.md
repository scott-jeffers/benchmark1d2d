# A2F-001 — Malpasset 1959

## Physics

Field-scale dam-break inundation following the 1959 Malpasset failure.
Validates 2D shallow-water models against surveyed high-water marks.

## Citation

Hervouet, J.-M., and Petitjean, A. (1999). "Malpasset dam-break revisited
with two-dimensional computations." *J. Hydraul. Res.*, 37(6), 777–788.
https://doi.org/10.1080/00221689909498511

Goutal, N. (1999). CADAM workshop test-case definition.
