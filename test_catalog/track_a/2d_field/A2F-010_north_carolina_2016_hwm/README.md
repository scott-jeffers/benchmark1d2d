# A2F-010 — North Carolina, October 2016: high-water marks

USGS data release [doi:10.5066/F75X276T](https://doi.org/10.5066/F75X276T): surveyed high-water marks, inundation polygons and depth rasters for seven communities after the October 2016 flood.

**Status: draft.** The next steps are to choose one reach, assemble lidar terrain and gauged inflows, and confirm the release's use constraints.
