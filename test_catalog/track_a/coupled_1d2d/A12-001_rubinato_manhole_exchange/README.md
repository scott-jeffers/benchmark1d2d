# A12-001 — Rubinato manhole exchange

## Physics

Coupled 1D sewer / 2D surface exchange through a manhole under steady and
unsteady surcharge. Exchange discharge depends on head difference and orifice /
weir regimes.

## Citation

Rubinato, M., Martins, R., Kesserwani, G., Leandro, J., Djordjević, S., and
Shucksmith, J. (2017). "Experimental calibration and validation of
sewer/surface flow exchange equations…" *J. Hydrol.*, 552, 421–432.
https://doi.org/10.1016/j.jhydrol.2017.06.024
