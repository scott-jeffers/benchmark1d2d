# A2L-EA4_flood_propagation_speed — EA4 flood propagation speed

## Physics

Environment Agency 2D hydraulic modelling benchmark case. Exercises 2D
shallow-water inundation, wet/dry fronts and floodplain storage.

## Citation

Néelz, S., and Pender, G. (2013). *Benchmarking the Latest Generation of 2D
Hydraulic Modelling Packages*. Report SC120002, Environment Agency.
